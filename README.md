#  NASA Solar System Simulation

Interactive Solar System simulation created using **Processing (Java)** with realistic orbital motion, self rotation, axial tilt, smooth camera controls, and animated space graphics.

---

# Features

- 🌍 Realistic planetary orbit motion
- 🔄 Planet self rotation
- 🪐 Axial tilt simulation
- 🌙 Earth–Moon system
- 🔍 Smooth zoom controls
- 🎥 Camera movement and drag system
- ⭐ Animated star field
- ☀️ Sun glow and corona effects
- 🖥️ Interactive HUD interface
- 🎮 Real-time keyboard and mouse controls

---

##  Controls

| Control | Function |
| Mouse Wheel | Zoom in / out |
| Mouse Drag | Move camera |
| W A S D | Camera movement |
| ↑ Arrow | Increase simulation speed |
| ↓ Arrow | Decrease simulation speed |

##  Technologies Used

- Processing (Java)
- 2D Computer Graphics
- Animation & Transformations
- Mathematical Simulation

##  Simulation Concepts

This project includes several computer graphics and simulation concepts:

- Orbital mechanics inspired by Kepler motion
- Planetary self rotation
- Axial tilt representation
- Smooth interpolation using `lerp()`
- Real-time rendering
- Interactive camera system
- Texture mapping using PNG images

## 🚀 How to Run

1. Install Processing:
   https://processing.org/

2. Download or clone this repository

3. Open:
   ```text
   solar_system_project.pde
   ```

4. Make sure all texture images are inside the `data` folder

5. Click ▶ Run in Processing
